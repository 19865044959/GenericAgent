# [Global Memory - L2]

## [购物偏好]
- 常用平台: 京东（电子/家电）、淘宝（衣服/日用品）
- 消费观念: 中等价位优先，不追求最便宜也不买最贵的，看重性价比和口碑
- 决策风格: 比较型 — 喜欢比2-3款后做决定，不冲动消费
- 购物频率: 数码产品半年一次，衣服季度买，日用品月度补
- 优惠敏感度: 会领券但不蹲点抢，有满减就用，不为凑单多买
- 售后态度: 有问题会退换，但懒得扯皮，小额就算了

  💻 数码电子产品

  - 数码预算: 手机 3000-5000元、笔记本 5000-8000元、外设 300-500元
  - 手机品牌偏好: 小米/红米优先，不排斥其他安卓
  - 笔记本偏好: 轻薄本、14寸、16G内存以上
  - 耳机偏好: 入耳式降噪、预算300以内
  - 电子品牌偏好: 小米系（性价比）、Apple（只买iPad，手机不用）

  👕 服装鞋帽

  - 风格偏好: 简约、纯色、休闲，不穿太花哨或大logo的
  - 衣服预算: T恤 20-200元、外套 100-500元、裤子 20-300元
  - 尺码: 上衣 M(175/96A)、裤子 30/31码、鞋 42码
  - 颜色偏好: 卡其色、白色、黑色、藏青，不穿红色/亮色
  - 品牌偏好: 优衣库（基础款）、选其他牌子时看面料不看logo
  - 鞋偏好: 运动鞋为主，偶尔帆布鞋，不穿皮鞋

  🍜 饮食

  - 饮食偏好: 不挑食，偏咸鲜口，微辣可以接受
  - 咖啡偏好: 美式/冷萃，不加糖，偶尔拿铁
  - 外卖预算: 午餐 25-40元、晚餐 30-50元
  - 常点品类: 川湘菜、麻辣烫/冒菜、盖浇饭、汉堡

  🏠 生活日用

  - 居住城市: 北京
  - 日用品偏好: 京东自营为主，看重次日达，不囤货用完再买
  - 家居风格: 简约风，偏好木质+白色系，不喜欢金属玻璃

  💳 支付与配送

  - 收件偏好: 工作日送公司、周末送小区，快递柜/驿站均可
  - 支付方式: 优先支付宝，偶尔微信
  - 会员: 京东Plus会员、饿了么会员
